Alert settings

Thresholds load when the station identity is available.

MPU angle thresholds

No calibration or Experimental Test mode is required. Each fresh reading is checked immediately using the larger absolute pitch or roll angle.

Angle = max(|pitch|, |roll|), relative to the sensor axes. A tilted installation can trigger immediately. This does not measure change from a mounted baseline.

Soil and rain ADC thresholds

Raw ADC readings create CAUTION alerts at the selected limit. Choose “At or below” if wetter conditions lower your sensor’s readings.

ADC values range from 0 to 4095. These are not wetness percentages or rainfall measurements.

Automatic monitoring

Alerts start when a fresh value meets or exceeds its limit (or falls to the selected lower ADC limit). A fresh reading in the normal range clears the condition. Missing or stale readings pause evaluation and keep existing alerts marked as unknown.

Settings are saved per station in this browser. Keep this dashboard open, visible and connected. Browser alert history lasts for this page session; device event history is stored separately on the server.
